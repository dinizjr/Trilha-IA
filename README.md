# Trilha de Inteligência Artificial

Repositório dedicado a estudos, exercícios e projetos práticos de Ciência de Dados e Inteligência Artificial, com foco na aplicação de técnicas de análise de dados e Machine Learning.

## 📂 Projetos

### 📊 Análise de Crédito

Projeto de análise de dados voltado à avaliação de risco de crédito, utilizando técnicas de tratamento, exploração e modelagem de dados.

**Etapas do projeto:**
- Análise exploratória dos dados (EDA).
- Tratamento e preparação da base de dados.
- Análise de variáveis relacionadas ao risco de crédito.
- Aplicação de algoritmos de Machine Learning.
- Treinamento de modelo de Regressão Logística.
- Avaliação do desempenho do modelo.

**Tecnologias e ferramentas:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

*O projeto está em desenvolvimento, e as etapas e os resultados serão atualizados conforme sua evolução.*
